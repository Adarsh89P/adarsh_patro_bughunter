# public/

Drop static assets here.

- `resume.pdf` — linked from the navigation, the hero's **View Resume** button and
  the contact section. The link is configured in `lib/content.ts` (`profile.resume`);
  add the file here, or point that value at an external URL.
- `character/`, `bugs/`, `illustrations/` — reserved for raster or Rive assets.
  The character, the bug and the boss are currently inline SVG components under
  `components/hero/`, so nothing is required here for the site to run.
